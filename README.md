# AeroOS - Your Airport, at Your Fingertips

AeroOS is the desktop that can use in airport terminal. Which is created using HTML, CSS and JavaScript.

The user can easily access and explore the OS for free, without any downloading external apps or without any passwords.

# Key Features
- Welcome Screen
- Real Time and Date based data
- Suitable aimations
- Glassmorphism theme
- Can open apps
- Multiple windows
- Close, Fullscreen, Miniscreen buttons are available
- Apps can drag as where you need
